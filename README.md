# AiPrise Token Sharing – Phase 1

Static site for GitHub Pages. No build step.

## Pages
- `index.html` – redirects to About
- `about.dc.html` – About Token Sharing
- `demo.dc.html` – Customer Overview and product demos
- `roadmap.dc.html` – Phase 1 and Roadmap
- `prototype.dc.html` – Prototype embedded by the demo page

## Publish
1. Push the contents of this folder to the root of a GitHub repo.
2. Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
3. Site is live at `https://<org>.github.io/<repo>/`.

Pages must be served over HTTP; opening the files directly from disk will not work.
